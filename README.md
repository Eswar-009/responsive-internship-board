# Responsive Internship Board — EdVyro Task 1

Built by Eswar R for the EdVyro Full Stack Development internship.

## Features
- Responsive layout for mobile, tablet and desktop
- Reusable internship card data rendered with JavaScript
- Search by internship title, company, domain or location
- Domain filter
- Empty state and error state
- Keyboard-friendly controls and visible focus states
- Semantic labels and live status updates
- No CSS/JS framework

## Responsive checks
Test the page at:
- 360px
- 768px
- Desktop width
